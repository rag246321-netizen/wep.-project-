# متجر رغد العطور - Perfume Store Project

### فكرة المشروع:
موقع ويب تعريفي وتسويقي متكامل لمحل عطور فاخر، يعرض المنتجات الأكثر مبيعاً بشكل منسق وجذاب ومتجاوب مع جميع الشاشات، ويحتوي على صفحة لطلب العطور المخصصة والتواصل مع إدارة المتجر.

### الأدوات المستخدمة:
- **HTML5:** لبناء الهيكل وتوزيع العناصر بشكل دلالي (Semantic Tags).
- **CSS3:** لتنسيق الألوان، الخطوط، وتوزيع العناصر لجعل التصميم متجاوباً (Responsive).
- **JavaScript (Vanilla JS):** لإضافة التفاعل، التحقق من المدخلات (Form Validation)، والتحكم بقائمة الجوال.

### هيكل المجلدات:
المشروع منظم بالكامل بناءً على الهيكلية المطلوبة (ملفات منفصلة لـ CSS و JS).
